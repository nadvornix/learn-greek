# 🏛️ Learn Greek Alphabet

An interactive web application for learning the Greek alphabet and ancient Greek vocabulary. Features 493 Greek words including mythology, gods, cities, scientific terms, medical terminology, and philosophical concepts.

![Demo](demo.gif)

## ✨ Features

- **493 Greek Words** - Comprehensive vocabulary covering:
  - Greek Gods & Mythology
  - Ancient Cities & Places
  - Greek Alphabet Letters
  - Scientific & Medical Terms
  - Philosophical Concepts
  - Common Words & Root Etymology

- **Interactive Learning**
  - Flashcard-style interface
  - Greek word display with random fonts (16 different serif fonts)
  - Transliteration (romanized pronunciation)
  - Letter-by-letter spelling (Alpha, Beta, Gamma...)
  - Detailed explanations with English derivatives

- **Navigation & Controls**
  - **Keyboard Shortcuts**:
    - `Enter` or `Space` - Reveal answer / Next word
    - `← →` Arrow keys - Navigate previous / next
  - **Touch Support**: Swipe left/right on mobile devices
  - Previous/Next buttons for manual navigation

- **Milestone Celebrations**
  - Confetti animation every 10th word! 🎉
  - Progress tracking with milestone messages

- **Mobile Responsive**
  - Optimized for phones and tablets
  - Touch-friendly interface
  - Swipe gestures support

## 📖 How to Use

1. **View the Greek Word** - Displayed in various classical serif fonts
2. **Try to Recall** - Think about the pronunciation and meaning
3. **Reveal** - Press `Enter`, `Space`, or click "Reveal" button
4. **Learn**:
   - See the transliteration (how to pronounce it)
   - Read letter-by-letter spelling
   - Understand the meaning and English derivatives
5. **Navigate** - Use arrow keys, swipe, or navigation buttons
6. **Celebrate** - Get confetti every 10 words!

## 🎯 Learning Examples

### Greek Gods
- **Ζεύς** (Zeus) - King of the gods, god of sky and thunder
- **Ἀθηνᾶ** (Athena) - Goddess of wisdom and warfare

### Medical Terms
- **ὀφθαλμός** (ophthalmos) - Eye → ophthalmology (medicine of eyes)
- **καρδία** (kardia) - Heart → cardiology (study of heart)

### Scientific Terms
- **φῶς** (phos) - Light → phosphorus (light bearer), photograph (light writing)
- **τηλε** (tele) - Far → telephone (distant sound), television (distant vision)
